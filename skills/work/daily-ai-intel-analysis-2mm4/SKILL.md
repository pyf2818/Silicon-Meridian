# 每日AI资讯情报分析技能

## 适用场景
- 用户给出"今日总判断"（如"2027-2028年本地强模型将重塑AI格局"），要求验证依据和可信度
- 用户要求从当日资讯中识别机会、风险、主要公司/技术对比
- 面向AI大模型、国内大厂、物联网5G、机器人、开源生态领域的每日情报工作

## 工作流程与方法论（四步法）

### 第一步：判断验证（判断类任务）
1. **拆解判断**为可验证的子命题（时间锚点、主体、影响机制三个层次）
2. **建立证据表**：每条相关资讯提取"来源类型（官方自证/第三方报道）→ 核心事实 → 与判断关联度 → 支撑强度"
3. **评估可信度**：支撑力度 + 削弱因素（时间线模糊、定义模糊、自证偏差、反例缺失）→ 给出 X/10 评分
4. **给出验证路径**：列出后续可追踪的具体指标（如"是否推出开源量化版"），标注"有依据的假设，建议持续追踪"

### 第二步：机会筛选（机会类任务）
1. **先校验证据边界**：用户提到的机会若不在当日证据集中，必须明确说明"无相关证据，无法确认"，不得编造
2. **只基于可用证据分析**：每个机会按"证据 → 可行性（高/中/低）→ 落地条件 → 建议动作"展开
3. **标注自证偏差**：厂商官方公告类证据（基准测试、用户数）必须标注"未经第三方验证"

### 第三步：公司对比（对比类任务）
1. **统一维度表**：核心产品、技术方向、能力跃升点、目标场景、部署形态、商业化进度、证据来源类型、第三方验证、可信度评分
2. **补充综合判断**：按"短期落地/技术突破/长期方向/基础设施"四个维度给出最看好项
3. **提炼结构性信号**：如"轻量竞赛""上下游互补"，而非罗列事实

### 第四步：风险扫描（风险类任务）
1. **识别信号**：按"风险等级（高/中/低）→ 信号 → 证据ID"列表
2. **逐项影响评估**：影响范围、严重程度、时间维度、关键信号、后续观察点
3. **综合风险矩阵**：概率 × 影响 → 建议动作
4. **区分结构性信号与单点事件**：如"Uber限额"比"OpenAI资本承压"更具行业结构意义

## 关键决策点与陷阱
1. **证据纪律**：所有事实必须引用 [资讯:ID]，ID不在证据集时明确说"无法确认"；禁止编造ID
2. **自证偏差识别**：官方基准测试、官方用户数均属自证，评分时自动降一档（如7→6）
3. **反例检索**：评估可信度时必须主动寻找削弱因素，不能只罗列支撑证据
4. **格式纪律**：禁用emoji；先列大纲再写正文；每段3-5句；表格承载数据
5. **输出规范**：结尾提供2个标题候选；风险分析末尾给出总体判断

## 输出模板
- 判断验证：拆解表 + 证据表 + 可信度评分 + 削弱因素 + 追踪指标
- 风险扫描：总览表 + 逐项影响评估表 + 风险矩阵 + 总体判断
- 公司对比：维度对比表 + 综合判断表 + 结构信号
- 统一要求：Markdown表格、无emoji、大纲先行
