# 多主体情报对比速览

## 适用场景
用户要求"对比今日资讯中的多个公司/技术"类任务；需要快速定位各主体当日信号、产出可沉淀的对比结论。

## 工作流程
1. 主体拆解：从用户问题或当日资讯高频词中确定 3-5 个对比主体（公司/模型/技术）。
2. 证据聚焦：对每个主体并行调用 read_intelligence_focus（topic=主体名，take=6-8），一次调用返回该主体的聚类情报。注意：聚焦结果可能混入其他主体噪音（如查 DeepSeek 会返回 OpenAI 内容），需按来源与摘要二次筛选。
3. 交叉比对：从"模型进展 / 成本效率 / 生态动作 / 战略信号 / 证据强度"五个维度拉齐各主体，标注置信度，识别只有单源支撑的信号。
4. 沉淀输出：先 save_knowledge 保存分析结论（type=knowledge），再在回复中以 markdown 表格呈现；表格必须逐条引用 [资讯:ID] 作为证据锚点。

## 关键决策点
- 主体数量：控制在 3-5 个，超过 5 个表格会失焦，需要合并弱主体或降权处理。
- 证据强度：单源信息（置信度 45-48%）标注为"待交叉验证"，不把观点类资讯当作事实断言。
- 降权来源：企业客户案例、纯观点争论类资讯，在对比表中用一句话带过，不占主体篇幅。
- 引用纪律：只引用 read_intelligence_focus / search_news 实际返回的 [资讯:ID]，不得编造。

## 工具经验
- read_intelligence_focus 是主力工具，一次调用可获得某主题全部相关事件，比多次 search_news 高效。
- 多主体并行调用：在同一个块内发起多个 read_intelligence_focus，无依赖关系，可节省轮次。
- save_knowledge 的 content 建议控制在 800-1200 字符，保留"要点+信号+下一步"三段式，便于素材库后续检索。
