# Paper Fast Read（论文快读：研究类内容快速解读）

## 适用场景
- 用户触发"论文快读"或要求解读论文/研究报告/官方技术测试
- 资讯流中混入研究类内容，需与其他新闻区分处理
- 输出目标为"素材沉淀"时，需产出可直接复用的素材卡片

## 工作流程
1. **筛选**：从资讯集中识别研究类条目（特征：研究机构署名、benchmark 测试、政策倡议、工程博客、技术白皮书），与商业新闻区分
2. **排序**：按信息密度（有无数据、有无方法、有无可复现性）降序排列，优先快读信息密度高的
3. **八维快读**：对每条输出——一句话结论 / 研究问题 / 方法数据 / 关键发现 / 局限 / 商业启示 / 素材卡片 / 证据级别
4. **证据分级**：标注证据级别：方向性（战略宣示）< 立场性（倡议/观点）< 自证数据（厂商官方测试）< 可复现（第三方可验证）
5. **自证降档**：官方自测数据（如 OpenAI benchmark）默认可信度降一档，明确标注"待第三方复现"
6. **横向对比**：4 篇以上时输出对比表（类型/证据级别/可复现性/商业信号强度/素材价值），并给出综合判断
7. **素材沉淀**：每条产出 1 行素材卡片（一句话，含关键数字与来源），可直接入库

## 关键决策点与陷阱
- 摘要级资讯不等于论文全文：不得编造方法细节、基准分数、消融实验；缺失信息明确写"无细节"
- 区分"研究宣示"与"可验证成果"：战略宣示 vs 官方测试数据，证据价值不同
- 商业信号强度优先于学术价值：素材沉淀给用户的是"算账素材"（成本、格局、卡位），不是学术综述
- 时间锚点缺失时明确说明，不替作者补时间线

## 工具使用经验
- 需要全文时可 fetch_page 抓取原文链接；资讯仅有摘要时以摘要为准
- 涉及厂商股价时可 get_stock_quote 辅助判断市场反应（可选）
