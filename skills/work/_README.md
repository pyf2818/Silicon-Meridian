# 工作沉淀技能

此目录存放 Agent 在工作过程中自动沉淀的技能。

## 沉淀机制

技能不是用户手动保存的，而是 Agent 在完成任务后自动反思归纳的：

1. **触发条件**：Agent 完成的任务满足以下两个条件时，系统自动触发技能沉淀：
   - 本次对话中有工具调用（如 search_news、web_search、fetch_page 等）
   - 输出包含结构化内容（标题/列表/步骤等）或长度超过 500 字

2. **沉淀过程**：
   - 系统向 Agent 发送"反思提示"，要求其回顾工作过程
   - Agent 被引导总结：适用场景、工作流程、关键决策点、工具使用经验、输出模板
   - Agent 调用 `create_skill` 工具，将方法论写入 `skills/work/<id>/SKILL.md`

3. **沉淀内容**（重点是过程，不是结果）：
   ```
   # 技能标题
   
   ## 适用场景
   ## 工作流程与方法论（分步）
   ## 关键决策点与陷阱
   ## 工具使用经验
   ## 输出模板
   ```

4. **使用方式**：当用户提问匹配技能的触发词时，系统自动推荐对应技能，Agent 可直接复用方法论。

## 来源

- Agent 任务完成后的自动反思沉淀（主要）
- 用户主动通过 `create_skill` 工具创建（辅助）
- 系统从 agent_memories 中提取的高置信度模式

## 格式

每个子目录一个 SKILL.md，结构与 `skills/builtin/` 相同。
