# 会议纪要

把凌乱的会议记录转化为可直接分发的高密度纪要，突出决议与行动项，便于跟进。

## Prompt 模板

```
请把以下会议记录转化为结构化纪要：

【原始记录】
{meetingNotes}

【输出结构】
1. 会议信息
   - 主题 / 时间 / 主持人 / 参会人（从记录中推断）
   - 时长估算（按字数/段落数粗估）
2. 议题清单（按讨论顺序，每议题 1-2 句话总结结论）
3. 关键决议（明确"决定了什么"，避免模糊表述）
4. 行动项表格（最重要部分）：
   | 任务 | 负责人 | 截止日 | 验收标准 |
   |------|--------|--------|----------|
   每条行动项必须可独立分配、可验收
5. 未决问题（讨论了但未达成共识的）
6. 下次会议建议议题（基于本次未决问题）

【风格要求】
- 决议用肯定句，不用"可能""也许""考虑"
- 行动项必须含负责人与截止日，缺则标注"待分配"
- 保留关键分歧观点（注明提出者）
- 删除寒暄/闲聊/重复内容
```

## 使用示例

用户输入："帮我把这段会议记录整理成纪要" / "做个会议总结"

Agent 匹配 triggers 后：
1. 直接按模板处理用户提供的原始记录
2. 输出表格化的行动项（markdown 表格）
3. 末尾附"建议下次议题"

## 注意事项

- 不依赖工具调用，纯文本处理
- 若原始记录信息严重不全（如只有片段），明确指出缺失项
- 涉及保密内容时，提示用户"建议删除敏感信息后再分发"
- 行动项截止日若记录中未提及，标注"待定"而非编造
- 多人会议需明确标注每条决议的提出者/反对者
