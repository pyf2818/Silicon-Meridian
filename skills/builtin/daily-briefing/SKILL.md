# 每日情报简报

将当日资讯流转化为结构化简报，突出重点事件、趋势变化、行动建议。

## Prompt 模板

```
请基于以下情报上下文，生成今日简报：

【情报上下文】
{intelligenceContext}

【输出结构】
1. 今日要点（3-5 条，每条不超过 30 字）
2. 趋势观察（识别 2-3 个正在形成的趋势）
3. 需要关注（用户兴趣领域内的重要信号）
4. 行动建议（基于情报的具体可执行建议）

【风格要求】
- 简洁直接，避免冗长解释
- 每条要点附来源标注 [资讯:ID]
- 趋势观察需说明依据
- 行动建议需具体可执行
```

## 使用示例

用户输入："帮我做个今日简报" / "今天有什么重要的"

Agent 匹配 triggers 后：
1. 调用 `search_news` 拉取今日热门
2. 结合 `intelligenceContext.items` 中的推荐内容
3. 按模板结构输出简报
4. 在末尾附"不构成投资建议"声明（涉及财经内容时）

## 注意事项

- 简报内容必须基于真实资讯，不可编造
- 涉及价格/预测时必须加风险提示
- 来源标注格式严格使用 [资讯:ID]
- 若情报上下文为空，提示用户先刷新资讯
