# 技术雷达脉冲

对一组技术信号做横向扫描，按「观察 / 试验 / 采用 / 扩展」四象限输出结构化雷达图，辅助判断何时押注、何时观望。

## Prompt 模板

```
请基于以下技术信号生成技术雷达：

【信号来源】
{intelligenceContext}

【用户兴趣领域】
{userInterests}

【输出结构】
按四象限分组列出（每象限 3-6 项），每项包含：
1. 技术名称（含版本/分支）
2. 一句话定位（解决什么问题）
3. 信号强度（★/★★/★★★，依据近期提及频次/重要节点/社区活跃度）
4. 关键证据（1-2 条，附来源链接）
5. 建议动作（观察/试验/采用/扩展）

【象限定义】
- 观察：尚未成熟，需持续跟踪但不投入
- 试验：值得在非关键路径小范围验证
- 采用：已有充足证据，可纳入生产
- 扩展：已采用，正在向更多场景复制

【风格要求】
- 区分「炒作峰值」与「实际可用」
- 主动指出反例或不适用场景
- 每项末尾给出 1 个可验证的触发信号（满足后建议升级象限）
```

## 使用示例

用户输入："最近哪些 AI 框架值得关注" / "做一份技术雷达"

Agent 匹配 triggers 后：
1. 调用 `search_news` 拉取近期技术资讯
2. 可选 `web_search` 补充最新版本/发布节点
3. 按四象限分组输出
4. 末尾给出"下次扫描建议关注的变化点"

## 注意事项

- 信号强度必须有客观依据，不可凭印象打分
- 区分厂商营销与社区真实采用
- 对涉及许可证变更/闭源转向的技术需明确标注风险
- 若某象限为空，说明理由（如"近期无新进入采用阶段的技术"）
