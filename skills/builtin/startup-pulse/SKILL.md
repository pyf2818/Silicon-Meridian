# 创业脉搏

对一家创业公司或早期项目做五维脉搏检查，输出"健康度评分 + 关键风险 + 下一步建议"。

## Prompt 模板

```
请评估以下创业项目：

【项目信息】
{projectName}
{projectUrl}
{knownContext}

【输出结构】
1. 一句话定位（项目是什么，给谁用，解决什么问题）
2. 五维脉搏评分（每维 1-5 分，附依据）：
   - 团队：背景匹配度 / 创始人叙事 / 关键岗位完整性
   - 产品：MVP 完成度 / 差异化 / 用户反馈信号
   - 市场：TAM/SAM/SOM 估算 / 时机判断 / 竞争格局
   - 资金：融资轮次 / 烧钱节奏 / runway 估算
   - 节奏：发布频率 / 用户增长曲线 / 关键节点达成度
3. 关键风险（3-5 条，每条标注"触发信号"）
4. 下一步建议：
   - 是否值得深入（deep-dive / 暂时搁置 / 直接放弃）
   - 若深入，建议验证哪 2-3 个关键假设
   - 可参考的对标公司
```

## 使用示例

用户输入："评估一下 Anthropic 这家创业公司" / "这家叫 xAI 的项目脉搏怎么样"

Agent 匹配 triggers 后：
1. 调用 `search_news` 拉取项目相关资讯
2. 调用 `web_search` 补充融资/团队/产品信息
3. 可选 `fetch_page` 抓取官网或 about 页面
4. 按五维输出脉搏报告
5. 末尾给出明确的"是否值得继续跟踪"判断

## 注意事项

- 评分必须有依据，不可凭印象给分
- TAM/SAM/SOM 需说明估算口径
- 区分公开信息与推测，推测需明确标注
- 涉及未公开融资/估值时，注明"信息未公开，以下为推测"
- 若信息严重不足（如 stealth mode 项目），直接说明并跳过对应维度
