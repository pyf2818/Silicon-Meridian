# 趋势追踪

对一个长期趋势做结构化跟踪，区分"信号"与"噪声"，输出当前阶段、关键触发点与建议动作。

## Prompt 模板

```
请基于以下信号对趋势 {trendName} 做结构化追踪：

【信号来源】
{intelligenceContext}

【历史追踪记录】
{historyContext}（若用户之前追踪过此趋势）

【输出结构】
1. 趋势定义（一句话明确"追踪的是什么"）
2. 当前阶段（五阶段之一）：
   - 萌芽：少数先行者关注，无成熟产品
   - 上升：资本/人才开始流入，首批产品出现
   - 加速：主流玩家入场，用户基数快速扩张
   - 顶峰：关注度达峰，出现"过热"信号
   - 衰退：替代技术出现，关注度下降
3. 信号强度雷达（5 维，每维 1-5 分）：
   - 资本信号：融资额/估值变化
   - 人才信号：关键人物流动/招聘需求
   - 产品信号：发布频率/产品成熟度
   - 用户信号：DAU/MAU/留存
   - 政策信号：监管态度/标准制定
4. 关键触发点（3-5 个，满足后建议升级/降级阶段）
5. 建议动作：
   - 介入时机（现在 / 等待 X 信号 / 已错过最佳窗口）
   - 介入方式（投资/学习/招聘/产品布局）
   - 退出信号（什么情况下建议撤退）
6. 反证与风险（这个趋势可能不成立的 2-3 个理由）

【风格要求】
- 阶段判断必须有依据，不凭印象
- 触发点必须可验证（具体数字/事件/时间点）
- 主动寻找反证，避免确认偏误
- 区分"长期趋势"与"短期热点"
```

## 使用示例

用户输入："追踪一下 AI Agent 这个趋势" / "趋势分析：Rust 在后端的采用"

Agent 匹配 triggers 后：
1. 调用 `search_news` 拉取近期相关资讯
2. 可选 `web_search` 补充融资/招聘/产品数据
3. 按结构化模板输出
4. 末尾给出"下次复盘建议关注的变化点"

## 注意事项

- 趋势判断必须有时间维度（"未来 6 个月"vs"未来 5 年"结论不同）
- 信号强度需说明数据来源与估算口径
- 主动指出数据盲区（如"中国市场的政策信号难以量化"）
- 不做价格预测，但可指出"哪些信号出现时价格通常会有反应"
- 涉及投资建议时必须加"不构成投资建议"声明
- 若用户之前追踪过此趋势，主动对比"上次判断 vs 现在的变化"
