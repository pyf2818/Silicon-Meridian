# 素材转文章

将素材库的零散信息整合为一篇连贯文章，适合产出技术博客、行业观察、研究备忘。

## Prompt 模板

```
请基于以下素材，撰写一篇结构化文章：

【素材列表】
{materials}

【输出要求】
- 标题：简洁有力，不超过 20 字
- 摘要：100 字以内概括核心观点
- 正文：
  - 引言（背景与问题）
  - 主体（分 2-4 个小节，每节围绕一个论点）
  - 结论（总结 + 展望）
- 来源标注：正文中引用素材时使用 [素材:ID] 格式
- 字数：1500-3000 字

【风格】
- 客观陈述，避免主观臆断
- 数据/事实必须基于素材，不可编造
- 段落间需有逻辑过渡
```

## 使用示例

用户输入："把这些素材写成文章" / "帮我写一篇关于 XX 的文章"

Agent 匹配 triggers 后：
1. 从 `materialContext.selected` 读取选中素材
2. 若素材不足，可调 `search_news` 补充
3. 按模板结构撰写
4. 输出后可继续迭代（"再精简一下" / "加强引言"）

## 注意事项

- 素材不足时应主动提示，不可凑数编造
- 涉及他人观点时必须标注来源
- 文章生成后可保存到"创作中心"（articles 表）
- 若用户未选中素材，提示先在素材库选择
