# 万般硅川 · 产品卓越路线图（走向世界一流）

> **北极星**：从「AI 资讯聚合站」升级为**世界一流的个人情报与创作操作系统**。
> 让用户从多源噪音中蒸馏出可行动的情报；让情报沉淀为可复用的知识与作品；让 AI 像一位懂你的首席情报官持续陪伴。

---

## 0. 现状一句话

**引擎层成熟，产品层（首屏、信息架构、空/错态、引导、效率工具）尚未与 v2 蓝图对齐**——这是从「功能堆」到「世界一流体验」的最大杠杆。

已有的牌：每日推荐闭环（Phase 2-6）、工作流引擎、股市终端、社区、画像 HUD、智创「熔炉」、GitHub 情报卡、竞争监测骨架、12 套调色板、6 大主域。

## 1. 六大维度自评（按你给的平衡要素）

| 维度 | ★现状 | 目标★★★★★ | 关键差距 |
|---|---|---|---|
| **功能完整性** | ★★★★ | 端到端闭环 | 简报引擎已就位但未首页化；素材→工作流→文章 需收口 |
| **便捷人性化** | ★★★ | 零摩擦、零学习成本 | 缺首跑引导；空/错/加载态未成体系；命令面板与键盘效率可再升 |
| **美观** | ★★★★ | 品牌级一致 | HUD/熔炉/全局 polish 已强；浅色暖色调 WIP；调色板与间距令牌可更系统化 |
| **智能** | ★★★★ | 像首席情报官 | LLM 推荐增强 + 画像闭环已就位；需「有/无 LLM」两套优雅降级 |
| **用户数据** | ★★★ | 数据归用户 | 画像/快照/记忆/趋势已沉淀；可视化 + 可导出 + 可分享 待补 |
| **一站式** | ★★★ | 进一个产品搞定 | 6 大域已覆盖；导航 9→6、首屏换骨是「一站式」最直观的表达 |

## 2. 关键战略缺口（按杠杆排序）

1. **首屏不是每日汇报**（违 v2 phase 6）——进站看到聊天而非今日情报，第一印象决定段位。
2. **导航未瘦身到 6**（违 v2 phase 1）——9 个主入口，焦点稀释。
3. **AI 精灵未浮窗化**（违 v2）——占首屏却非核心体验。
4. **RSS 失败率 ~40-50%**——情报产品的命门是「信源活、信号真」。
5. **缺统一空/错/加载态设计系统**——世界级产品永不死胡同。
6. **缺新用户首跑引导**——便捷人性化的入口门槛。
7. **无 e2e / 组件测试**——世界级工程底盘。
8. **鉴权强依赖 PG**（已有 DEV_MEMORY_AUTH 沙盒兜底）。
9. **无 PWA / 离线壳 / 安装体验**——一站式的延伸。

## 3. 分阶段路线图（与 v2 蓝图对齐）

> 引擎层（✅ 已完成大半）：v2 phase 2-6 画像/工作流/推荐闭环、phase 3-6 仪表盘、智创「熔炉」、股市、社区、GitHub 情报、竞争监测骨架。

### Phase A · 首屏重生（v2 phase 1+6 收口）— 杠杆 ★★★★★
- 「每日汇报」（现 `recommendations` 简报引擎）**设为首页 / 默认落地**，重塑为可扫描、可行动的情报首页：今日精选 + 推荐理由 + 机会/风险 + 追踪信号 + 可沉淀素材 + 选题建议 + 画像快照引用。
- 主导航瘦身至 **6 项**（每日汇报 / 全部动态 / GitHub 热门 / 智创中心 / 用户广场 / 用户画像）；股市、竞争监测转为能力卡片或高级入口。
- AI 精灵 → **全局浮窗**（右下召唤），不占首屏。

### Phase B · 世界级 UX 底盘 — 覆盖面 ★★★★★
- 统一 **空 / 错 / 加载态** 设计系统（Skeleton · Friendly Empty · Actionable Error；含 LLM 未配置时的优雅引导）。
- **首跑引导**（Onboarding）：兴趣 → 信源 → 配置 LLM（或先算法降级）→ 第一份简报，3 步内。
- **命令面板**（Ctrl/K）补全：导航 + 动作 + 搜索 + 最近 + 主题 / 重预热。
- **键盘效率**：`g+d` / `g+g` / `g+s` / `g+p` 跳转；`Esc` 关层；`?` 快捷键面板。
- **错误边界**补齐懒加载组件，友好降级。

### Phase C · 情报可信度
- RSS 治理：源健康度看板、自动重试 + 退避、按源历史成功率排序、多源交叉验证徽章（M4 延伸）。
- **有 / 无 LLM 双模式**：未配置时算法满血 + 「升级 AI 简报」引导，永不死胡同。
- 质量护栏可见化：去重、相似度、时效分、来源等级——引擎已有，强化 UI 表达。

### Phase D · 一站式创作闭环（智创「熔炉」深化）
- 素材库 → 工作流 → 文章 → 导出 / 分享 全链路打磨，减少跨页跳转。
- 版本 / 草稿 / 发布显式化；引用追溯可视化。
- 一键从每日汇报 / 画像洞察跳转到工作流编排。

### Phase E · 用户数据资产化
- 画像 / 快照 / 趋势 **可导出**（JSON / Markdown）、**可分享**（只读链接）。
- 数据看板：阅读时长分布、领域占比、信号雷达——让用户「看见」自己的成长。
- 隐私：本地优先 + 一键清除所有行为信号。

### Phase F · 工程卓越
- **e2e + 组件测试**（Playwright 沙盒坑已知可绕）。
- 性能：首屏 LCP / INP，仪表盘虚拟化 / 懒加载。
- **PWA**：installable、离线壳（最近一次简报可看）、后台预热。
- i18n 全覆盖审计（中英）+ 右键菜单等所有面板。
- 鉴权：保留 `DEV_MEMORY_AUTH` 沙盒兜底；PG 路径加固。

## 4. 质量底线（对应 v2 §10）

- 不做只有边框的空壳页面；不做 prompt 列表式智能体；不继续在 App.jsx 无限堆逻辑。
- 每个模块有真实数据结构与用户操作闭环。
- 所有视觉变更需**截图 + mock data 验证**（你的视觉验证主义）。
- 每次推进只增量 **1 个可验证的相位**，绝不大跃进导致不可回滚。
